#  Installation

## Clone Repository

```bash
git clone https://github.com/ritesh-tech280/Cognifyz.git
```

## Navigate to Project

```bash
cd your-repository
```

## Install Dependencies

```bash
npm install
```

## Start Backend

```bash
npm start
```

or

```bash
npm run dev
```
